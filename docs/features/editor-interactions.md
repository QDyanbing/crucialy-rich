# 编辑区交互

本页说明 React 编辑区的点击、内嵌控件和选区归属。文档与受控选中态仍由宿主管理，不新增模型、Command 或事件字段。

## 点击顺序

- 宿主 `onClick` 先执行；已取消的事件不再触发内部事务、图片/单元格选择或清除通知。
- 只读态不执行内部点击动作，链接默认行为仍交给浏览器；宿主可自行取消链接。
- 编辑态仅处理最近编辑器根节点属于当前实例的目标。内嵌按钮、输入控件和 `contenteditable=false` 区域交给宿主，已验证的模型图片和任务复选框除外。
- Composition 活跃时不执行内部点击动作；正常点击不能提前勾选任务、切换图片/单元格选中态或提交候选。文字会话仍使用开始时的锚点，结束后可继续正常点击。

## 模型目标

图片点击要求合法的顶层 image 路径；单元格点击要求合法的三段 tableCell 路径。错误路径、类型不匹配或结构端点不会触发选中/清除通知。正常图片点击通知宿主选择图片并清除旧 cell；正常 cell 点击通知选择 cell 并清除旧图片。它们不编辑文档，也不新增 History。

任务点击要求 checkbox 与合法 taskItem 路径，支持已有嵌套层级。checked 的新值来自 `!taskItem.checked`，而不是 DOM.checked；即使 DOM 属性被外部改过，也不以它覆盖模型。任务勾选继续直接创建既有 `set_task_item_checked` Operation，并输出一条 `setTaskItemChecked` 事务；没有新增任务 Command，也不把 Registry 当成勾选权限系统。

React 只读态和 Composition 活跃期间会实际禁用任务复选框，避免仅取消原生 click 带来的视觉勾选变化。恢复编辑或结束/取消组合后重新启用。这是 React 组件的交互状态，不改变 Core 的独立 renderDocument/HTML 输出和模型 schema；禁用控件是否产生 DOM 事件遵循浏览器规则。

## 文字输入归属

`onBeforeInput`、`onNativeBeforeInput`、`onKeyDown`、`onCopy`、`onCut`、`onPaste` 仍先交给宿主。内嵌控件、不可编辑区域和嵌套编辑器的事件不继续进入外层文字处理，不读取/写入外层剪贴板，也不因为外层处理而取消控件原生默认行为。宿主自行取消或处理事件不由组件撤销。

读取 DOM Selection 时，两端必须同时位于当前实例内，且最近编辑器根节点均为当前根。即使外层收到事件，也不会把嵌套编辑器同路径的 Range 当成自己的正文。这里隔离的是外层处理，不代表组件原生支持任意嵌套编辑器的布局、状态共享或协同编辑。

Demo 的 keydown、keyup 和 mouseup 同样跳过内嵌控件/嵌套实例的文字同步与快捷键，防止旧 Range 回写抢走复选框焦点。焦点停在任务复选框时，原生空格键每次只勾选一次；不会同时删除、插入文字或执行旧文字范围的快捷键。

## 选区与 History

任务事务优先保留当前实例合法 DOM Range，其次使用合法受控 selection；都不可用时使用被点击任务第一段文字的起点。beforeSelection 和操作后 selection 独立复制，修改前快照不会污染后选区或宿主 prop。正反方向保留，勾选作为无 typing batch 的独立事务，可记录单条 History 并撤销/重做；受控 value 仍等待宿主回传结果。

当焦点位于当前根内的原生控件或嵌套编辑器时，受控文字 selection 的 layout effect 暂缓回写 DOM，防止模型更新抢走控件焦点。没有增加 blur 自动回写；宿主需要恢复文字范围时，应回到编辑区并更新 selection。组件不替宿主管理所有焦点或产品级面板。

## 边界

- 不检测文档、payload 或 DOM 的所有原地修改，不验证合法路径是否被宿主重新指向另一个同类型节点；路径校验不是防篡改或权限机制。
- 不回滚宿主/扩展副作用，不捕获宿主回调异常，不新增异步调度或窗口级焦点监听。
- 测试覆盖合成 Composition、原生空格键及桌面/手机视口，不代表所有真机输入法序列均已验收。
