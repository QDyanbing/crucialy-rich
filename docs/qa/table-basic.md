# QA：基础表格闭环

## 验收范围

| 场景         | 预期                                       | 结果 |
| ------------ | ------------------------------------------ | ---- |
| 默认创建     | `createTable()` 生成 3×3，节点引用互相独立 | 通过 |
| Schema       | cell 只包含 paragraph，各行列数一致        | 通过 |
| 非法结构修复 | 空表补 1×1，短行补齐，非法子节点移除       | 通过 |
| Path         | 可定位 row、cell、paragraph 和 text        | 通过 |
| 插入与删除   | 光标处分段插入，删除后恢复文本选区         | 通过 |
| 行操作       | 首行前后添加，删除最后一行时移除表格       | 通过 |
| 列操作       | 首列前后添加，删除最后一列时移除表格       | 通过 |
| 渲染         | 输出语义 table 结构与完整模型路径          | 通过 |
| Demo         | 中文入口可插表、删表和增删首行首列         | 通过 |
| 浏览器回归   | 操作后 DOM 尺寸正确且模型保持合法          | 通过 |

## 自动化覆盖

- Vitest 覆盖类型、工厂、守卫、校验、规范化、深拷贝、路径、渲染和全部表格命令。
- Playwright 覆盖 3×3 插入、增删行、增删列、删表和校验状态。
- 完整质量门禁使用 `pnpm check:all`。
