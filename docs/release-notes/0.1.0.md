# crucialy-rich 0.1.0 发布说明草稿

> 状态：发布候选，尚未创建 Git tag、npm 发布或 GitHub Release。

## 版本亮点

- 自研文档模型、Selection、Operation、Transaction、Command 和 History 内核。
- 独立图片 BlockSelection 支持安全 HTML 复制和可编辑单图剪切，React 要求根聚焦与 DOM 选区归属，写入图片 HTML 和空纯文本成功才通过 `deleteImage` 删除；失败不删除，剪切/粘贴可分别撤销。默认 plain 不输出图片、只读不执行模型剪切，受限目标边界不变，块选区由宿主管理。
- 图片删除/剪切事务的 `beforeSelection` 现为可选：没有合法旧文字范围时省略，接入方读取端点须判空。新增 `beforeBlockSelection`，传给 `createHistorySnapshot` 可选第三参数后，宿主可回传撤销结果恢复图片高亮；未接入时仍只恢复内容。
- History 快照、撤销/重做和 Command 结果可带独立的块选区，两种自动合并策略都不合并含块选区的 entry。Demo 已接入按钮/快捷键、旧高亮清除和图片选中时的悬浮文字工具栏隐藏，补齐 Core/React/构建包及桌面/手机浏览器回归。不扩展多图片选择、单元格矩形选择或剪切范围。
- 顶层正文之间完整选中的列表、表格、分隔线及安全图片引用支持混合 HTML 复制，保留顺序并裁剪首尾，正文粘贴形成单条 History；不支持的图片或结构内部与正文混选仍回退纯文本，跨结构剪切边界不变。
- 图文复制只写出模型 ready、无凭据的 HTTP/HTTPS URL、alt 和正安全整数尺寸，不复制文件字节、临时 blob/loading/error 或内部属性，不验证远端可达性。
- History 可选相邻输入合并策略，Demo 在保留连续 typing 合并的同时支持换格、光标跳变、选区替换及撤销分支后的独立撤销；Core 默认 batch 契约保持不变。
- 模型纯文本与可选安全 HTML 复制/剪切、宿主事件接管和剪切 History 往返；同层跨列表项可保留结构、起始编号、任务状态及选区内子列表；同一行跨 cell 片段或完整连续行保留表格、多段内容和文字格式。只读可复制，写入失败与跨项/跨结构文字剪切不删除。不支持任意跨层级列表、部分跨行/跨表结构写出或多图片块剪切。
- React 受控/非受控编辑器、模型选区同步、Command Registry 和 imperative ref API。
- 文本样式、行内代码、链接、标题、引用、代码块、分隔线、列表、任务列表、图片和表格。
- 固定/悬浮工具栏、斜杠菜单、纯文本/HTML/Markdown 粘贴、HTML/Markdown 行内代码与分隔线、HTML 文字标记别名、安全行内文字属性与 boolean mark CSS、链接元数据、有序列表起始编号、三层嵌套列表、安全图片、任务列表与表格导入，以及 TSV 表格填充。
- 中文输入法 Composition、Mark/Heading/Quote/List 编辑快捷键和 Markdown 输入规则。
- 同容器跨 text 与连续顶层文本块的输入替换、删除和 Enter 分段。
- 空引用按 Enter 退出正文，以及选区清空引用后的 Enter 退出。
- 表格 Tab／Shift+Tab 按行前后换格，更新选区与高亮但不生成 History；首尾不扩表，DOM 选区按编辑器实例隔离。
- 五种 boolean mark 与三种文字属性支持跨连续 paragraph、heading、quote 应用、取消和 History 往返。
- Link Mark 支持跨连续 paragraph、heading、quote 创建、覆盖、取消、统一状态读取和 History 往返。
- 中文调试 Demo、Vitest、Playwright 与公开包产物导入检查，最新执行数量见[全量回归记录](../qa/full-regression.md)。

## 安装

```sh
pnpm add @crucialy-rich/core@^0.1.0
pnpm add @crucialy-rich/react@^0.1.0 react react-dom
```

运行环境要求 Node.js `>=22.14.0 <23`，React 与 React DOM 支持 `>=18 <20`。

## 已知边界

- 不包含协同编辑、评论、权限、服务端存储和服务端历史版本。
- History 状态和撤销重做接入由宿主维护。
- 图片上传、链接菜单主题和产品样式由宿主实现。
- 普通输入替换已覆盖同一文本容器跨 text 节点和连续顶层文本块；暂不跨越列表、表格、图片或分隔线等结构节点。
- HTML 表格导入暂不保留 `colspan`、`rowspan`、`th` 语义或嵌套表格结构。
- HTML／Markdown 普通段落图文混排会拆为文字段落和独立图片块；不保留行内环绕或图片链接，不扩展列表项／cell 内部图片模型，不接受 data URL，也不负责上传或持久化图片资源。
- HTML 任务列表导入要求每个直属项以 checkbox 开始，暂不重建嵌套任务列表。
- HTML 文字标记导入识别语义标签与白名单内的 `font-weight`、`font-style`、`text-decoration`；其他 CSS 值不会推断 boolean mark。
- HTML 链接导入只保留白名单内的 target/rel，href 仍只接受绝对 HTTP、HTTPS 和 mailto 地址。
- HTML 列表导入每个列表项只保留第一个直接子列表，并在三层模型上限处省略更深结构。
- HTML 分隔线导入只保留 Divider 语义，不保留来源元素的样式、类名、标识或事件属性。
- 当前只发布 ESM 构建，不提供 CommonJS 入口。
