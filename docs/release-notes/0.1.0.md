# crucialy-rich 0.1.0 发布说明草稿

> 状态：发布候选，尚未创建 Git tag、npm 发布或 GitHub Release。

## 版本亮点

- 自研文档模型、Selection、Operation、Transaction、Command 和 History 内核。
- 编辑区点击统一遵守宿主取消、只读/组合保护和最近实例归属，图片/cell/任务目标校验模型路径，任务以模型 checked 切换，正常图片选中清理旧 cell。原生控件/嵌套实例不借用外层 Range，控件获焦时暂缓文字选区回写，Demo 不再通过 keyup 同步抢走复选框焦点；空格连续勾选各产生单条 History。受控、快照、SSR 与浏览器范围见[编辑区交互](../features/editor-interactions.md)。
- 工具栏按下范围绑定文档、Registry、按钮命令与 payload 引用，跨上下文操作取消；执行前保存 event.selection、执行/回调前消费手势，取消和重试不复用旧范围。每次渲染刷新可变 Registry 状态；新增可选 `disabled` 和低层 `onCommandCancel`，Demo 组合期间禁用固定/悬浮按钮。默认九类命令、正反向 History、失败恢复、构建包及桌面/手机回归见[工具栏](../features/toolbar.md)。
- Slash 执行先核对当前 paragraph 的触发内容及精确范围，过期菜单不再清理其他正文；事件/导航触发快照隔离，默认十类块命令仍合并单条 History。同树菜单 DOM ID 按实例生成，Demo 组合期间不抢键盘/点击，修饰键交给编辑流程，Shift+Enter 保留软换行；详见[斜杠菜单](../features/slash-menu.md)。
- 修复 Composition 状态/通知 Range 共享、宿主取消和同一 compositionend 回退重复提交；文档引用变化、只读或块选区清理旧会话，未配对结束不插入文字。受控接入须保持未编辑 value 引用稳定；History batch 和 API 不变，取消与事件序列范围见[中文输入法](../features/ime.md)。
- 原生 `insertParagraph` 复用已有 Enter 规则；Shift+Enter/原生 `insertLineBreak` 在同一文字容器插入 LF，不拆块或退出列表/代码块，独立进入 History。事务联合类型新增 `insertLineBreak`，穷尽 switch 的宿主需要补分支；模型不新增节点，宿主用保留 LF 的 CSS 展示。图片块选中时 Enter 不改旧文字范围，见[换段与软换行](../features/input.md#换段与软换行)。
- React 新增可取消原生 `beforeinput deleteContentBackward/Forward`，无 keydown 时复用文字、范围与图片删除管线；可选 `onNativeBeforeInput` 同步观察/取消原始 DOM InputEvent，不替换 React `onBeforeInput`。键盘、History、受控回传、IME 和选区归属保持既有边界；监听器可更新、卸载及 SSR 安全，详见[原生删除意图](../features/input.md#原生删除意图)。
- 折叠 Backspace/Delete 删除完整字素簇，避免 emoji、组合重音、旗帜或 ZWJ 被拆坏，并支持同一容器内跨格式叶子；修复中间叶子末尾 Delete 提前合并下一段的问题。非法光标不进入结构回退，History 保留前后 UTF-16 光标，Point 和显式范围 API 不变。
- 修复 History 初始化及记录时共享旧 entry 的问题：空事务、追加和合并均隔离保留记录，嵌套模型、事务、撤销重做及宿主保存分支不相互污染。公开签名不变；栈顶查询仍返回当前状态的 entry 引用，不再与初始化输入 entry 引用相等。复制成本随保留快照总体积增长，详见[状态引用与隔离](../features/history.md#状态引用与隔离)。
- 独立图片 BlockSelection 支持安全 HTML 复制和可编辑单图剪切，React 要求根聚焦与 DOM 选区归属，写入图片 HTML 和空纯文本成功才通过 `deleteImage` 删除；失败不删除，剪切/粘贴可分别撤销。默认 plain 不输出图片、只读不执行模型剪切，受限目标边界不变，块选区由宿主管理。
- 图片删除/剪切事务的 `beforeSelection` 现为可选：没有合法旧文字范围时省略，接入方读取端点须判空。新增 `beforeBlockSelection`，传给 `createHistorySnapshot` 可选第三参数后，宿主可回传撤销结果恢复图片高亮；未接入时仍只恢复内容。
- History 快照、撤销/重做和 Command 结果可带独立的块选区，两种自动合并策略都不合并含块选区的 entry。Demo 已接入按钮/快捷键、旧高亮清除和图片选中时的悬浮文字工具栏隐藏，补齐 Core/React/构建包及桌面/手机浏览器回归。不扩展多图片选择、单元格矩形选择或剪切范围。
- 修正 DOM 元素子节点偏移与拆分 Text 的 UTF-16 累计/恢复，容器真实边界不再被任务 checkbox 或外层空白/注释错移。复制、剪切、输入、ref 和 History 恢复共用修正，不读取 DOM 作为模型内容，不扩大复杂包装或跨结构编辑边界；公开 API 签名保持不变。
- 同步 Command 扩展异常转为失败/不可用，工具栏异常项禁用、Slash 失败不泄露清理事务；剪贴板源读取/parser/直接过滤回调异常中止，正常拒绝继续降级。键盘命令失败不再进入旧删除 fallback，Enter/格式快捷键不退回原生 DOM 修改；范围删除禁用与图片失败不误删，Delete 合并前快照保存实际光标。
- 异常保护不等于权限系统或副作用回滚，只覆盖同步入口；宿主回调、异步扩展和 React 构造合成事件前的原生 clipboardData 属性异常不在范围内。详情见[扩展异常边界](../features/command.md#扩展异常边界)与[读取失败](../features/paste.md#读取与回调异常)。
- 顶层正文之间完整选中的列表、表格、分隔线及安全图片引用支持混合 HTML 复制，保留顺序并裁剪首尾，正文粘贴形成单条 History；不支持的图片或结构内部与正文混选仍回退纯文本，跨结构剪切边界不变。
- 图文复制只写出模型 ready、无凭据的 HTTP/HTTPS URL、alt 和正安全整数尺寸，不复制文件字节、临时 blob/loading/error 或内部属性，不验证远端可达性。
- History 可选相邻输入合并策略，Demo 在保留连续 typing 合并的同时支持换格、光标跳变、选区替换及撤销分支后的独立撤销；Core 默认 batch 契约保持不变。
- 模型纯文本与可选安全 HTML 复制/剪切、宿主事件接管和剪切 History 往返；同层跨列表项可保留结构、起始编号、任务状态及选区内子列表；同一行跨 cell 片段或完整连续行保留表格、多段内容和文字格式。只读可复制，写入失败与跨项/跨结构文字剪切不删除。不支持任意跨层级列表、部分跨行/跨表结构写出或多图片块剪切。
- React 受控/非受控编辑器、模型选区同步、Command Registry 和 imperative ref API。
- 文本样式、行内代码、链接、标题、引用、代码块、分隔线、列表、任务列表、图片和表格。
- 固定/悬浮工具栏、斜杠菜单、纯文本/HTML/Markdown 粘贴、HTML/Markdown 行内代码与分隔线、HTML 文字标记别名、安全行内文字属性与 boolean mark CSS、链接元数据、有序列表起始编号、三层嵌套列表、安全图片、任务列表与表格导入，以及 TSV 表格填充。
- 中文输入法 Composition、Mark/Heading/Quote/List 编辑快捷键和 Markdown 输入规则。
- 同容器跨 text 与连续顶层文本块的输入替换、删除和 Enter 分段。
- 空引用按 Enter 退出正文，以及选区清空引用后的 Enter 退出。
- 表格 Tab／Shift+Tab 按行前后换格，更新选区与高亮但不生成 History；首尾不扩表，DOM 选区按编辑器实例隔离。
- 五种 boolean mark 与三种文字属性支持跨连续 paragraph、heading、quote 应用、取消和 History 往返。
- Link Mark 支持跨连续 paragraph、heading、quote 创建、覆盖、取消、统一状态读取和 History 往返。
- 中文调试 Demo、Vitest、Playwright 与公开包产物导入检查，最新执行数量见[全量回归记录](../qa/full-regression.md)。

## 安装

```sh
pnpm add @crucialy-rich/core@^0.1.0
pnpm add @crucialy-rich/react@^0.1.0 react react-dom
```

运行环境要求 Node.js `>=22.14.0 <23`，React 与 React DOM 支持 `>=18 <20`。

## 已知边界

- React 只读/组合期间任务复选框现在带 disabled，原生事件行为由浏览器决定；Core 独立渲染和公开签名不变。控件获焦时不强制回写文字 selection，不新增 blur 自动恢复；宿主需要回到编辑区并更新选区。路径校验不是 DOM 防篡改或权限系统，不回滚宿主副作用，也不宣称支持任意嵌套编辑器产品或所有真机 IME。
- 工具栏默认未禁用，原调用继续可用，但旧手势跨文档/Registry/按钮命令/payload 引用时会取消；内容相等的新文档也视为替换，配置 payload 应保持稳定引用。可变 Registry 不自动触发渲染，不检测模型或 payload 原地变异、不重映射旧范围，也不捕获宿主回调异常；窗口级释放监听、其他宿主控件及真机 IME 全面兼容不由本轮保证。`event.selection` 是操作前快照，操作后位置读取 `result.selection`。
- Slash 公共签名不变，但失效触发现在返回 failure，且事件/导航的 trigger 不再与输入对象共享引用；内部 DOM ID 不再由配置 ID 拼接。独立 SSR 根需设置各自的 `identifierPrefix`。校验只检查当前位置的内容/范围，不校验文档身份或当前光标，不自动重映射旧选区；自定义宿主仍需处理组合输入和菜单刷新。
- Composition 文档身份按引用判断，相等内容的新对象仍会取消活跃会话；不检测原地模型修改、不重映射旧锚点，也不保证所有 IME 在结束后另发 textInput/insertFromComposition 的跨事件序列。单次结束事务不等于不同会话强制分开撤销，仍遵循宿主原合并策略。
- 字素删除依赖运行时 `Intl.Segmenter`，不内置 polyfill，按运行时 Unicode 规则分段；不进行字符串规范化、按词删除或字素光标导航。手机视口用例不等同于真实软键盘 `beforeinput` 删除兼容性验收，详见[输入规则](../features/input.md#字素删除与-utf-16)。
- 原生编辑仅处理可取消的 `deleteContentBackward/Forward`、`insertParagraph` 和 `insertLineBreak`；不根据 targetRanges 扩展选区、不事后修复不可取消事件的 DOM 修改，也不转换 deleteWord/软行删除等未支持类型。宿主可在原生回调取消这些事件；尚未完成跨平台真机软键盘验收。
- 不包含协同编辑、评论、权限、服务端存储和服务端历史版本。
- History 状态和撤销重做接入由宿主维护。
- 图片上传、链接菜单主题和产品样式由宿主实现。
- 普通输入替换已覆盖同一文本容器跨 text 节点和连续顶层文本块；暂不跨越列表、表格、图片或分隔线等结构节点。
- HTML 表格导入暂不保留 `colspan`、`rowspan`、`th` 语义或嵌套表格结构。
- HTML／Markdown 普通段落图文混排会拆为文字段落和独立图片块；不保留行内环绕或图片链接，不扩展列表项／cell 内部图片模型，不接受 data URL，也不负责上传或持久化图片资源。
- HTML 任务列表导入要求每个直属项以 checkbox 开始，暂不重建嵌套任务列表。
- HTML 文字标记导入识别语义标签与白名单内的 `font-weight`、`font-style`、`text-decoration`；其他 CSS 值不会推断 boolean mark。
- HTML 链接导入只保留白名单内的 target/rel，href 仍只接受绝对 HTTP、HTTPS 和 mailto 地址。
- HTML 列表导入每个列表项只保留第一个直接子列表，并在三层模型上限处省略更深结构。
- HTML 分隔线导入只保留 Divider 语义，不保留来源元素的样式、类名、标识或事件属性。
- 当前只发布 ESM 构建，不提供 CommonJS 入口。

## 发布前操作

1. 确认仓库 CI 与本地 `pnpm check:all` 均通过。
2. 确认 npm 包名和发布权限。
3. 创建 `v0.1.0` tag。
4. 发布 core 后再发布 React 包。
5. 创建 GitHub Release，并采用本草稿作为说明基础。
